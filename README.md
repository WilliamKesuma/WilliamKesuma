# 👋 Hi! Im William

Developer trained through the Apple Developer Academy @ UC Indonesia, focused on building polished, production-ready apps with Swift & SwiftUI.

I shipped 5+ apps across iOS, iPadOS, and macOS during the Academy, averaging a 4.8/5 pilot satisfaction score. My favorite build is Menata, which uses RoomPlan, Object Capture, and RealityKit to let interior designers scan and arrange rooms in 3D.

Beyond mobile, I bring full-stack range — AWS serverless architecture and time-series forecasting — so I can work closely with backend and data teams while owning the iOS experience end to end.

I'm also deliberately growing alongside AI tooling — using models like Claude, Gemini, and Copilot inside AI-native editors (Antigravity, Cursor) to move faster, and shipping to Vercel to close the loop from prototype to production.

`📦 5+ shipped projects` &nbsp;·&nbsp; `🛠️ 3 years building` &nbsp;·&nbsp; `🎓 GPA 3.71 / 4.0`
